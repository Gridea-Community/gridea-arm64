# v0.9.3-arm64.1.beta.7

## 简体中文

本次更新包含以下依赖项更新：

- 更新 Electron，以及网络通信、Git 发布和文件处理等依赖
- 更新本地预览和订阅生成相关依赖，调整站点目录切换，并保留现有文章和标签链接格式
- 更新界面使用的字体、图标、Emoji 面板和过渡动画依赖
- 更新 Vue 2 的组件类和属性装饰器依赖
- 升级 Markdown 编辑器及相关插件，涵盖 Emoji、脚注、图片、标记和上下标等功能
- 统一 KaTeX 公式渲染、样式和字体版本，生成页面使用本地配套资源，避免旧主题样式与新版公式不匹配
- 调整编辑器的依赖加载，避免重复打包，并减少反复打开文章时的重复注册
- 完善 SFTP 发布的目录检查和上传结果判断，改进特殊路径及上传失败时的处理
- 更新构建工具和类型声明，并补充 Markdown、编辑器及 SFTP 的回归检查

**Beta 8 预告**：下一版计划迁移至 Vue 3，部分界面和操作可能有细微变化。

Gridea for ARM64 是基于 Gridea 0.9.3 的社区维护版本，面向搭载 Apple 芯片的 Mac，无需 Rosetta。

## English

This update includes the following dependency updates:

- Update Electron and dependencies used for networking, Git publishing, and file operations.
- Update local preview and feed-generation dependencies, adapt site directory switching, and preserve existing post and tag URL formats.
- Update the interface font, icon set, emoji picker, and transition library.
- Update the Vue 2 component class and property decorator libraries.
- Upgrade the Markdown editor and plugins for emoji, footnotes, images, highlighting, subscripts, and superscripts.
- Align KaTeX rendering, styles, and fonts. Generated pages use matching local resources to prevent conflicts with older theme styles.
- Adjust editor dependency loading to avoid bundling a second editor and reduce repeated registrations when reopening articles.
- Improve SFTP directory validation and upload result handling, including paths with special characters and failed uploads.
- Update build tools and type definitions, and add regression checks for Markdown, the editor, and SFTP.

**Beta 8 preview**: The next release is planned to migrate to Vue 3, with possible minor changes to the interface and how some controls work.

Gridea for ARM64 is a community-maintained version based on Gridea 0.9.3, built for Macs with Apple silicon. Rosetta is not required.
